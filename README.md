# Manga Reader (офлайн-рідер для власної бібліотеки)

Простий Android-застосунок на Kotlin + Jetpack Compose для читання манги/манхви,
яку ти вже маєш локально у форматі webp. Застосунок нічого нізвідки не скачує —
він лише читає файли з обраної тобою папки на телефоні.

## Очікувана структура папок

```
<Обрана коренева папка>/
  Назва манги 1/
    Том 1/
      1 - 001.webp
      1 - 002.webp
      2 - 001.webp
    Том 2/
      3 - 001.webp
      ...
  Назва манги 2/
    ...
```

Назва файлу має бути у форматі `<номер розділу> - <номер сторінки>.webp`
(саме так, як зберігає твоя завантажувалка). Якщо в папці тайтла немає
підпапок-томів — застосунок сприйме саму папку тайтла як один том.

## Як зібрати APK

1. Встанови **Android Studio** (безкоштовно, з офіційного сайту developer.android.com).
2. Відкрий цю папку (`MangaReader/`) як проєкт в Android Studio — вона сама
   підтягне Gradle та всі залежності (потрібен інтернет один раз, при першому
   відкритті).
3. Дочекайся синхронізації Gradle (внизу праворуч буде прогрес-бар).
4. Підключи телефон по USB, увімкни на ньому "Налагодження USB" (Developer
   options → USB debugging).
5. Натисни зелену кнопку ▶ (Run) — застосунок збереться і встановиться на
   телефон.

Або, якщо хочеш просто .apk файл:
`Build → Build Bundle(s)/APK(s) → Build APK(s)`, готовий файл буде в
`app/build/outputs/apk/debug/app-debug.apk` — його можна перекинути на
телефон і встановити напряму (потрібно дозволити встановлення з невідомих
джерел).

## Як користуватись

1. Кабелем скидай нові тайтли у будь-яку папку на телефоні (наприклад,
   `Внутрішня память/Manga/`), дотримуючись структури вище.
2. Відкрий застосунок → "Обрати папку" → вибери саме **кореневу** папку
   (ту, що містить папки з назвами тайтлів, а не окремий тайтл).
3. Застосунок просканує вміст і покаже бібліотеку з обкладинками (перша
   сторінка кожного тайтла).
4. Тапни на тайтл → побачиш список томів і розділів → тапни на розділ, щоб
   почати читати.
5. У рідері є перемикач режиму (іконка вгорі): вертикальний безперервний
   скрол (зручно для манхви) або горизонтальне гортання сторінка за
   сторінкою (зручно для манги).
6. Прогрес (на якій сторінці ти зупинився в кожному тайтлі) зберігається
   автоматично і підвантажується при наступному відкритті.

## Що можна доробити далі

- Кешування мініатюр для швидшого відкриття бібліотеки.
- Пошук/фільтр по бібліотеці.
- Підтримка .cbz/.zip архівів без розпакування.
- Жести (тап по краях екрана для гортання сторінок).

Скажи, якщо щось із цього треба додати — допоможу розширити код.
